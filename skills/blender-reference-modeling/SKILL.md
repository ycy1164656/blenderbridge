# 参考图建模

与 `$blender-bridge` 配合使用。先读取项目规则、资产复用要求、当前批准概念图和已拒绝模型的具体差异。工具改善迭代与证据，不保证模型自动达到参考图质量。

## 先建立可判断的目标

记录参考文件、对象范围、尺寸/比例、正侧背与主要视角、材质语义、运动/部署结构、交付路径和当前授权。参考只有一个视角时，把不可见结构的设计推断明确标出。不要把不同视角的生成图当作必然几何一致。

先做一个代表性资产或局部结构，验证轮廓、装甲分层、机械连接和镜头。不要在首件尚不合格时复制出整批塔或整套机甲。

## 分阶段制作

1. **比例与轮廓**：用明确顶点/轮廓线建立大形，可用基本体起步，但必须编辑截面、转折、厚薄和负空间。选择固定相机和正交前/侧/背视图，渲染灰模，与批准图比较头身比、肩宽、躯干/腿长和外轮廓。不得用更多小零件掩盖大形差异。
2. **结构**：制作主装甲面、次级覆盖、接缝、关节与承力件。用 inset/extrude/bevel、布尔/镜像/厚度等明确操作。装甲要有可读平面和层级；机械连接不能浮空；塔的底座/旋转/升降/展开结构须能解释运动。每几次结构编辑检查网格、固定角度灰模和局部近景。
3. **材质与细节**：大形成立后才安排材质角色、UV、贴图与磨损。高对比材质不能弥补缺失体积，黑色缝线不能代替真实装甲厚度。避免大量均匀圆角造成玩具感。需要烘焙/雕刻/重拓扑时先核对目录是否具备能力；缺失就报告或实现能力，不能伪称已完成。
4. **运动与游戏资产**：视觉结构达到当前批准标准后再绑定骨骼、权重、动作、导出。检查零面积面、非预期开口/非流形边、法线、UV、权重归一、关节运动、回姿态、单位与轴向。开放壳体是否可接受取决于用途，不用单一“非流形=0”作通用艺术标准。
5. **交付与验收**：保存可继续编辑的 `.blend`，纹理有路径或打包，精确选择 FBX 对象；在独立 Blender 进程重读源文件和 FBX。提交固定 Before/Final、多视图、局部图与真实差异说明。参考图、美术模型、技术导出、UE 导入/运行、用户视觉接受分别报告。

## 质量门槛与迭代

- 默认候选 960×540，最终证据 1920×1080；项目另有约定则遵循。最多保留 2～3 个工作候选，历史证据和恢复备份不随便删除。
- 每次预览明确目标对象，检查画面有没有被默认 Cube、旧候选或道具遮挡。使用 `blender_view_image` 实际看图，不能只检查 PNG 存在。
- 自评未达到参考图时直接说明具体差距并继续修形；不把不合格候选交给用户替自己判断。没有新的实现路线时诚实说明能力限制。
- 用户要求中途审核时只在对应阶段等待，不反复索要已给授权。用户未要求每步审核时自主完成范围内迭代，但不能宣称用户接受。
- 当前 ShooterRoyal 塔/机甲重制：保留旧版本，使用新 Revision 输出；此前 R2/R3 未通过视觉要求，不能因换用 Bridge 就称其合格。UE 写入走项目独立授权与精确保存规则。
